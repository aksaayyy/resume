# Interactive Resume — Akshay Kumar

A colorful, product-page-style interactive resume built with vanilla HTML, CSS, and JavaScript.

**Live site:** [https://aksaayyy.github.io/resume/](https://aksaayyy.github.io/resume/)

## Features
- Smooth scroll-powered animations via **GSAP** + **Lenis**
- Colorful gradient hero with floating blobs
- Scroll-triggered section reveals (skills, experience, projects, education, contact)
- Responsive layout
- Single-file architecture (`index.html`)

## Tech Stack
- HTML5 / CSS3 (custom properties, keyframes, transforms)
- [GSAP](https://greensock.com/gsap/) (ScrollTrigger)
- [Lenis](https://lenis.studiofreight.com/) (smooth scroll)
- [Lucide Icons](https://lucide.dev/)
- [Google Fonts](https://fonts.google.com/)

## Usage
The resume is fully self-contained in `index.html`. Open it in any modern browser, or visit the live GitHub Pages link above.

> **Note:** The "Download PDF" button in the resume currently links to `Akshay_Kumar_AI_Backend_Engineer_Resume_1Page.pdf`. If you have a PDF version of your resume, add it to the repo root so the download works on the live site.
